# CITS3403 Group Project

### Description
A web application that allows users to create quizzes and play them with each other. Created by Adam Young (23817456), Darrell Ek (24849609), Pranav Menon (24069351), and Rundong Wu (24441894)

### Usage:
Use the command `python run.py` in the project directory. The command `flask run` will not work, as the project requires WebSockets.
